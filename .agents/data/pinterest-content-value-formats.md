# ElevateLivingCo — Pinterest Content Value Formats

**Version:** 1.0  
**Last Updated:** 2026-09-29  

This matrix defines 12 reusable information-dense Pin formats designed to communicate scannable, actionable value before the user clicks, establishing a legitimate curiosity gap.

---

## 1. The 12 Reusable Content Value Formats

### 📋 FORMAT A — QUICK LIST
- **Structure:** `[SHORT HEADLINE] + 3--5 Key Items`
- **Example:**
  ```text
  DARK ACADEMIA ESSENTIALS
  01 Vintage clothbound books
  02 Warm amber banker lamp
  03 Leather journal & fountain pen
  04 Antique brass accents
  05 Stoneware ceramic crock
  ```

### 🎯 FORMAT B — HOW-TO / ACTIONABLE STEPS
- **Structure:** `[PROBLEM/GOAL HEADLINE] + 3--4 Action Steps`
- **Example:**
  ```text
  MAKE A SMALL APARTMENT FEEL EXPENSIVE
  01 Scale furniture to room dimensions
  02 Layer 3 warm lighting sources
  03 Use leggy low-profile seating
  04 Keep surfaces 30% un-cluttered
  ```

### ☑️ FORMAT C — CHECKLIST
- **Structure:** `[NICHE CHECKLIST HEADLINE] + 4--5 Checkbox Items`
- **Example:**
  ```text
  DARK ACADEMIA STUDY CHECKLIST
  □ Clothbound classic book stacks
  □ 2700K warm desk lamp
  □ Full-grain leather blotter
  □ Brass vintage hourglass
  □ Natural eucalyptus branches
  ```

### 🔄 FORMAT D — BEFORE / AFTER COMPARISON
- **Structure:** `BEFORE vs AFTER Contrast`
- **Example:**
  ```text
  ENTRYWAY TRANSFORMATION
  BEFORE: Flat, cluttered, un-lit surface
  AFTER: Slim shoe cabinet + round mirror + warm lamp pool
  ```

### ⚖️ FORMAT E — 3 GOLDEN RULES
- **Structure:** `[NUMBER] RULES FOR [OUTCOME] + 3 Rules`
- **Example:**
  ```text
  3 RULES FOR MOODY LIGHTING
  01 Ditch overhead recessed lights
  02 Pool warm light at eye level (2700K)
  03 Use cordless amber accent lamps
  ```

### ⚠️ FORMAT F — COMMON MISTAKES TO AVOID
- **Structure:** `[NUMBER] MISTAKES TO AVOID + 3--4 Warnings`
- **Example:**
  ```text
  4 DARK ACADEMIA DECOR MISTAKES
  • Painting walls flat jet black
  • Overcrowded un-edited shelves
  • Cold white light bulbs (>3000K)
  • Matching fake plastic props
  ```

### 🧪 FORMAT G — STYLING FORMULA / RECIPE
- **Structure:** `[OUTCOME FORMULA] = Element 1 + Element 2 + Element 3`
- **Example:**
  ```text
  COZY SMALL SPACE FORMULA
  Scaled low furniture
  + 3 warm lighting layers
  + Vertical storage wall
  + Natural textured linens
  ```

### 🛍️ FORMAT H — PRODUCT + PRINCIPLE
- **Structure:** `[DESIGN PRINCIPLE HEADLINE] + Functional Benefit + Product Staged`
- **Example:**
  ```text
  WARM TASK LIGHTING
  Creates a focused scholarly pool of light
  [Brass Banker's Lamp Staged Naturally]
  ```

### 📐 FORMAT I — MEASUREMENT / SPATIAL CLEARANCE
- **Structure:** `[SPATIAL RULE] + Precise Clearance Guideline`
- **Example:**
  ```text
  NARROW FOYER CLEARANCE RULE
  Keep console depth under 12 inches to preserve 36 inches of walkway space
  ```

### 🛋️ FORMAT J — ROOM RECIPE
- **Structure:** `[ROOM TYPE] = Anchor + Accent + Lighting`
- **Example:**
  ```text
  SCHOLARLY READING NOOK
  Oxblood leather wingback chair
  + Brass floor lamp with parchment shade
  + Plaster wainscoting backdrop
  ```

### 🔄 FORMAT K — "DO THIS, NOT THAT"
- **Structure:** `DO THIS vs NOT THAT Comparison`
- **Example:**
  ```text
  BOOKSHELF STYLING
  DO THIS: Mix vertical & horizontal stacks
  NOT THAT: Pack books flat edge-to-edge
  ```

### ⏱️ FORMAT L — QUICK WIN
- **Structure:** `[5-MINUTE FIX] + Single High-Impact Action`
- **Example:**
  ```text
  5-MINUTE LIGHTING FIX
  Swap stark 5000K bulbs for 2700K warm amber LEDs in your desk lamp
  ```

## 2. Information Governance Rules

1. **NO FAKE NUMBERS OR STATISTICS:** Every statistic, measurement, or list count MUST be extracted directly from the source article. Never invent percentages or popularity claims.
2. **NO BLAND TITLE REPETITION:** A Pin text overlay that merely repeats the article title is a **FAIL**. It must present 2–4 scannable value points.
3. **LEGITIMATE CURIOSITY GAP:** Provide immediate scannable value on the Pin while reserving complete step-by-step layout formulas for the article (*"5 rules shown — explore all 12 layout steps inside"*).
