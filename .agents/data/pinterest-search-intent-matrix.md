## 2. Intent Dimension Definitions

1. **INSPIRATIONAL:** Visual mood boards, luxury transformations, aesthetic aspirations. Reader wants visual ideas to save to boards.
2. **INFORMATIONAL:** Step-by-step styling rules, layout formulas, educational guides. Reader wants to learn *how* to achieve a look.
3. **COMMERCIAL:** Curated product picks, shop-the-look listicles, affiliate recommendation roundups. Reader wants specific items to buy.
4. **TRANSACTIONAL:** Direct buy signals, exact item sourcing, budget-specific bundles. Reader is ready to click through to Amazon.
5. **SEASONAL:** Time-bound holiday or seasonal decorating (Fall, Christmas, Spring Reset). Reader is preparing for an upcoming season.
6. **STYLE/AESTHETIC:** Specific interior design sub-cultures (Dark Academia, Old Money, Quiet Luxury, Neo Deco). Reader identifies with a distinct vibe.
7. **PROBLEM/SOLUTION:** Practical pain-point fixes (no wall damage, dark room, zero entryway floor space, clutter). Reader needs a fix.
8. **SMALL-SPACE:** Constraints-based urban apartment living, studio zoning, compact room scaling. Reader has limited square footage.
9. **ROOM-SPECIFIC:** Target room focus (Entryway, Bookshelf, Desk, Kitchen, Living Room, Patio). Reader is decorating one specific area.

## 3. Automated Pin Concept Mapping Rule

When generating a new Pin concept:
1. Identify the Primary Intent of the target keyword from this matrix.
2. If **Style/Aesthetic**, use **Editorial Split Panel / Dark Panel** visual design with serif typography.
3. If **Problem/Solution**, use **Numbered Listicle / Infographic** visual design with high-contrast text panel.
4. If **Seasonal**, include **Seasonal Color Palette & Contextual Badge** (e.g., Autumn Gold / Renter-Friendly).
5. If **Commercial**, include explicit **Shop-The-Look / Sourced Items Callout** in the editorial footer.
