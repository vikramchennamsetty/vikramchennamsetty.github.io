## 2. Automated Visual Concept Assignment Rule

When generating a 5-Pin campaign for a single article:
1. **Pin 1 (Primary Search Intent):** Use **Hero Room** or **Functional Space** concept.
2. **Pin 2 (Secondary Keyword):** Use **Styled Vignette** or **Detail Shot** concept.
3. **Pin 3 (Practical Use-Case):** Use **Small-Space Solution** or **Product-in-Room** concept.
4. **Pin 4 (Aesthetic/Editorial):** Use **Architectural View** or **Lighting-Focused Scene** concept.
5. **Pin 5 (Niche/Long-Tail):** Use **Lifestyle Editorial** or **Vignette** concept.

Each Pin MUST carry a distinct visual concept, lens focal length, focal object, lighting direction, and text-safe zone position to enforce 100% campaign visual diversity.
