# Elevate Pinterest Pin Composition Skill (V1.0)

## 1. PURPOSE
Combines generated architectural interior photography backgrounds with structured, scannable text overlays (`HEADLINE`, `VALUE_POINTS`, `CURIOSITY_GAP_CTA`, `BRAND`) to produce final 1000x1500px 2:3 vertical Pinterest Pin graphics.

---

## 2. COMPOSITION LAYOUT INGREDIENTS

Every Pin composition accepts these 5 inputs from Content Intelligence & Image Generation:
1. **BACKGROUND ASSET:** `/assets/pinterest/[cluster]/[filename].jpg`
2. **TEXT-SAFE ZONE:** `TOP_THIRD` / `BOTTOM_THIRD` / `LEFT_SIDE` / `RIGHT_SIDE`
3. **LEVEL 1 HEADLINE:** Main promise hook (Serif / bold Sans-serif)
4. **LEVEL 2 VALUE POINTS:** 2–4 concise bulleted/numbered scannable points
5. **LEVEL 3 CURIOSITY CTA & BRAND:** Destination cue + `ElevateLivingCo.me` brand footer

---

## 3. TYPOGRAPHY & VISUAL HIERARCHY RULES

### A. Font Hierarchy (1000x1500px Scale)
- **Level 1 (Headline Hook):** `48px -- 64px` Playfair Display / Inter Bold (High contrast).
- **Level 2 (Value Points):** `28px -- 34px` Inter Semi-Bold / Medium (Clear line spacing).
- **Level 3 (CTA & Brand):** `22px -- 26px` Inter Bold / All-Caps (`ElevateLivingCo.me`).

### B. High-Contrast Panel Standards
- **Dark Backgrounds:** Ivory/White text on semi-transparent dark charcoal overlay box (`rgba(17,17,17,0.85)`).
- **Light Backgrounds:** Espresso/Dark text on semi-transparent warm ivory overlay box (`rgba(250,248,245,0.90)`).
- **Padding:** Minimum `32px` interior padding around text blocks.
- **Image Dominance:** Text overlay MUST NOT cover more than `35%` of total 2:3 frame area. The interior photograph MUST remain visually dominant.

---

## 4. FINAL COMPOSITION QUALITY CHECKLIST

- [ ] Headline hook is scannable in $< 2$ seconds.
- [ ] 2–4 value points are legible at 375px mobile viewing size.
- [ ] Text panel is placed strictly inside the designated Text-Safe Zone.
- [ ] Background photograph is not obscured or overcrowded.
- [ ] Brand signature `ElevateLivingCo.me` is present at the base.
