# Elevate Pinterest SEO Skill

## Overview

The `elevate-pinterest-seo` skill governs search visibility on Pinterest. It translates high-performing editorial reference patterns into search-optimized titles and descriptions using structured Product-Led Listicle copy formulas.

## Niche + Mood System

Every Pin campaign must explicitly map:
- `NICHE`: e.g., Small Apartment Decor, Dark Academia, Patio Design
- `SUB_NICHE`: e.g., Narrow entryway, small foyer, balcony seating
- `AUDIENCE`: Small space dwellers, renters, aesthetic interior enthusiasts
- `PROBLEM_DESIRE`: Decluttering narrow entryways, creating warm atmosphere
- `PRODUCT_ROLE`: Primary functional solution (e.g., flip-drawer shoe cabinet)
- `MOOD`: Warm luxury, scholarly moody, minimalist clean
- `EDITORIAL_ANGLE`: X essentials / X layout secrets
- `SEARCH_INTENT`: Informational research + commercial investigation

## Product-Led Editorial Listicle Copy Formulas

- `[NUMBER] + [NICHE] + [OUTCOME]`
  - Example: *7 Narrow Entryway Products That Save Floor Space*
  - Example: *10 Small Apartment Entryway Essentials for a Clean Foyer*
  - Example: *8 Storage Pieces That Make Small Entryways Look Custom*

## Rules & Constraints

- **Title Limit:** $\le 100$ characters. Front-load primary keyword naturally.
- **Description Limit:** $\le 500$ characters. Rich natural language, zero keyword-stuffing.
- **Saveability & Click-Through Alignment:** Ensure description details the saveable listicle value and points to full layout instructions in the destination article.
