## 3. Phase 19 Hard Stop Rules (AUTOMATED HALT)

> [!CAUTION]
> **ANTIGRAVITY MUST HALT EXECUTION AND REQUEST DIRECTIVES WHEN ANY HARD STOP IS TRIGGERED:**

1. **HISTORICAL VERSION UNCLEAR:** Commit baseline of an article or file is ambiguous.
2. **IMAGE REPLACEMENT UNVERIFIED:** Local image asset or external replacement cannot be verified.
3. **ASIN MISMATCH:** Mismatch between anchor `href`, `trackAffiliate`, image wrap, title, or schema.
4. **DESTINATION CHANGED UNEXPECTEDLY:** Commercial destination URL changes unexpectedly.
5. **SEO METADATA CHANGED UNEXPECTEDLY:** Meta title, description, canonical, or schema changes without request.
6. **PROTECTED FILE ALTERED:** A protected file (`index.html`, `404.html`, `sitemap.xml`, etc.) is targeted without instruction.
7. **HOMEPAGE ALTERED UNEXPECTEDLY:** Homepage layout changes during an article task.
8. **PRODUCT IDENTITY AMBIGUOUS:** Ambiguity exists regarding physical item identity.
9. **ASSET LICENSE UNCLEAR:** Commercial rights or license of visual asset cannot be verified.
10. **SOURCE INFORMATION CONFLICTS:** Conflicting data across project CSVs, HTML DOM, or docs.
11. **BROWSER DIVERGENCE:** Headless browser rendering state differs unexpectedly from static analysis.

## 4. Mandatory Production Change Gate

Before declaring a production-impacting task complete, Antigravity MUST execute the 10-step Production Change Gate:
1. **PRECHECK & MANIFEST:** Record `git status` and create Article Protection Manifest.
2. **SOURCE DEPENDENCY INVENTORY:** Identify all consumer HTML files and imported stylesheets.
3. **IMPLEMENT:** Apply minimal surgical edits to target files.
4. **STATIC VALIDATION:** Validate HTML syntax, CSS rules, ASIN parity, and regex checks (`href="#"` == 0, `return false` == 0).
5. **BROWSER UAT:** Execute real browser test runner across 8 viewports and parameter strings (`?utm_source=...`).
6. **VISUAL QA:** Capture rendered screenshots at 375px and 1440px; verify computed presentation.
7. **ACCESSIBILITY QA:** Test keyboard focus state (`:focus-visible`) and `prefers-reduced-motion: reduce`.
8. **100% CONSUMER REGRESSION QA:** Re-test 100% of consumer pages identified in Step 2.
9. **PRODUCTION CHANGE MANIFEST & GIT DIFF:** Generate Change Manifest and review `git diff` for zero collateral edits.
10. **COMPLETION DECISION:** Declare completion ONLY if all gates pass cleanly.
