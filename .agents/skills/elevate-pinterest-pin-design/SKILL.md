# Elevate Pinterest Pin Design Skill

## Overview

The `elevate-pinterest-pin-design` skill enforces brand-consistent, mobile-first visual design standards for all Pinterest Pins. It incorporates high-performance editorial reference patterns (`PIN-REFERENCE-DARK-ACADEMIA-001`) and 10 structural Pin archetypes.

## Technical Specifications

- **Dimensions:** 1000 × 1500 pixels (Standard 2:3 aspect ratio).
- **Format:** High-quality PNG or WebP visual assets.
- **Safe Margins:** Keep key text overlays $\ge 100\text{px}$ from top/bottom edges and $\ge 60\text{px}$ from side edges.

## 10 Standard Pin Archetypes

1. **ARCHETYPE-A: `EDITORIAL_LISTICLE`** (Canonical reference: Numbered list of items + atmospheric scene).
2. **ARCHETYPE-B: `PRODUCT_ESSENTIALS`** (Curated breakdown of key space solutions).
3. **ARCHETYPE-C: `ROOM_TRANSFORMATION`** (Before/after layout principles & visual guide).
4. **ARCHETYPE-D: `PROBLEM_SOLUTION_PRODUCT`** (Specific problem heading + product solution).
5. **ARCHETYPE-E: `STYLE_FORMULA`** (Visual breakdown of materials, palette, and key accents).
6. **ARCHETYPE-F: `PRODUCT_COMPARISON`** (Side-by-side or stacked option comparison).
7. **ARCHETYPE-G: `ROOM_CHECKLIST`** (Saveable step-by-step room decor checklist).
8. **ARCHETYPE-H: `MOODBOARD_WITH_ACTION`** (Cohesive aesthetic collage + concrete takeaways).
9. **ARCHETYPE-I: `SAVEABLE_GUIDE`** (Infographic reference guide with dimensions/placement rules).
10. **ARCHETYPE-J: `SPECIFIC_PRODUCT_IN_CONTEXT`** (Verified single product featured in a styled room scene).

## Saveability & Click-Through Gates

- **Saveability Gate:** A Pin MUST offer standalone reference value (checklist, numbered essentials, layout formula, dimensions) that justifies saving to a board.
- **Click-Through Gate:** A Pin MUST create a logical information gap that the full destination article fulfills (e.g., specific placement rules, dimension guides, product reviews).
- **Commercial Balance:** Editorial value first $\rightarrow$ Product context $\rightarrow$ Why it fits $\rightarrow$ Commercial CTA.

## Product-Specific Visual Accuracy Rule

- If a Pin names a specific product, verified imagery must be used if available.
- If verified imagery is unobserved, the visual MUST represent the **PRODUCT CATEGORY** contextually rather than misrepresenting a generic generated object as a specific named product.
