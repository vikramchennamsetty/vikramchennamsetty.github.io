## 1. Visual Decomposition & Structural Formula

```
┌─────────────────────────────────────────────────────────┐
│ [TOP]  NUMBER + NICHE/TOPIC (10 Dark Academia...)       │
│        EMOTIONAL / FUNCTIONAL PROMISE (Elevate Space)   │
├────────────────────────────┬────────────────────────────┤
│ [LEFT PANEL]               │ [RIGHT PANEL]              │
│ Numbered List of 10        │ Atmospheric visual scene / │
│ Concrete Essentials        │ Styled room environment    │
│ Short benefit beneath each │ Cinematic lighting         │
│ High-contrast gold typography                           │
├────────────────────────────┴────────────────────────────┤
│ [BOTTOM] CLEAR CTA / NEXT ACTION                        │
└─────────────────────────────────────────────────────────┘
```

### A. Format
- **Ratio:** 2:3 vertical aspect ratio.
- **Composition:** Split vertical balance with text-dense left panel and atmospheric editorial photograph on the right.

### B. Information Architecture
- **Headline:** Large numeric hook (`10 DARK ACADEMIA ESSENTIALS`).
- **Subheadline:** Emotional outcome (`To Elevate Your Space`).
- **Body:** 10 concrete, numbered items with micro-copy explanations under each.
- **Visual Hierarchy:** Primary title $\rightarrow$ Numbered items $\rightarrow$ Micro-descriptions $\rightarrow$ Call-to-action.
- **CTA:** Bottom action block encouraging saves/clicks.

### C. Visual Composition & Color Direction
- **Background:** Moody dark canvas (charcoal/deep brown).
- **Typography:** Warm gold serif and crisp cream sans-serif for high readability.
- **Borders & Ornaments:** Thin gold framing rule with subtle micro-icons for each item.
- **Lighting:** Warm ambient lamp light and rich shadows creating depth.

### D. Psychological & Editorial Hooks
- **High Information Density:** Offers immediate standalone reference value.
- **Completion & Curiosity:** Numbered lists incentivize scrolling and saving for future design projects.
- **Saveability Guarantee:** Functions as a design checklist users save to personal decor boards.

## 2. Product-Led Archetype & Niche/Mood Framework

### Archetype Definition: `EDITORIAL_LISTICLE` / `PRODUCT_ESSENTIALS`
Combines specific niche styling with concrete, actionable product categories or verified items.

### Niche + Mood Matrix Requirement
Every high-priority Pin concept must define:
- `NICHE`: e.g., Dark Academia, Small Apartment, Modern Minimalist
- `SUB_NICHE`: e.g., Scholarly apartment, narrow entryway, small foyer
- `AUDIENCE`: Renter, small space owner, aesthetic-first decorator
- `PROBLEM_DESIRE`: Space optimization, aesthetic transformation
- `PRODUCT_ROLE`: Primary solution (e.g., flip-drawer cabinet, wall hooks)
- `MOOD`: Warm luxury, moody vintage, minimalist bright
- `MATERIALS`: Brass, dark walnut, textured linen, jute
- `LIGHTING`: Warm ambient 2700K lighting
- `EDITORIAL_ANGLE`: X essentials for a functional space
- `SEARCH_INTENT`: Informational research + commercial investigation

---

## 3. Product-Specific Visual Accuracy Protocol

1. **Verified Product:** If a Pin explicitly names a specific product ASIN or brand model, the visual must represent that exact product or an accurate image source.
2. **Category Fallback:** If verified product imagery is unobserved, the Pin must represent the **PRODUCT CATEGORY** in a contextual editorial scene rather than presenting a generic generated object as a specific named product.

---

## 4. Saveability & Click-Through Decision Tree

Before generating any Pin, evaluate:
- **Saveability Value:** Does the Pin contain a checklist, layout formula, dimensions, or list that gives users a reason to save it?
- **Click-Through Gap:** Does the Pin create an information gap that the full destination article fulfills (e.g., layout placement, dimensions, installation guidance)?
- **Commercial Balance:** Editorial value first $\rightarrow$ Product context $\rightarrow$ Why it fits $\rightarrow$ Optional commercial action.
