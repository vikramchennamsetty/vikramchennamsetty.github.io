# Elevate Pinterest 3D Editorial Skill (v1.0.0)

## Overview

The `elevate-pinterest-3d-editorial` skill is a specialized visual-design extension for creating distinctive 3D editorial Pins using architectural cutaway and product visualization techniques.

It operates as an add-on visual specialist skill and does not redefine core Pinterest SEO, scheduling, analytics, or compliance governance established by core Elevate skills.

## Core 3D Pin Principle

> **3D MUST COMMUNICATE INFORMATION.**  
> 3D visualization must not exist merely for visual flair. Every 3D Pin must convey layout relationships, spatial optimization, dimensions, or material formulas clearly to the viewer.

## Visual Language & Palette

- **Architectural Surfaces:** Deep charcoal, smoked glass, dark slate, dark walnut wood.
- **Metal Accents:** Antique brushed brass, muted warm gold.
- **Typography:** Warm cream serif headlines with clean high-contrast sans-serif supporting text.
- **Lighting:** Warm architectural sconce illumination (2700K), soft amber highlights, deep readable shadows.
- **Aesthetic:** High-end architectural miniature / Architectural Digest editorial visualization. Avoid gaming, neon, or futuristic sci-fi tropes.

## 10 Add-on 3D Archetypes

1. **`3D_PRODUCT_SCENE`:** Spatial breakdown of key product categories in a styled room.
2. **`3D_ROOM_CUTAWAY`:** Architectural miniature room cutaway highlighting floorplan placement.
3. **`3D_LISTICLE`:** Numbered 3D spatial list showing concrete organization items.
4. **`3D_PRODUCT_EXPLODED_VIEW`:** Exploded component view explaining storage mechanics.
5. **`3D_SPACE_OPTIMIZATION`:** Visualizing clearance, door sweeps, and floor footprint savings.
6. **`3D_STYLE_FORMULA`:** 3D material and texture formula breakdown.
7. **`3D_BEFORE_AFTER`:** Spatial before/after 3D model comparison.
8. **`3D_DIMENSION_GUIDE`:** 3D infographic depicting exact measurements and clearances.
9. **`3D_MATERIAL_MOODBOARD`:** 3D material composition board with lighting reference.
10. **`3D_ARCHITECTURAL_PIN`:** High-level isometric room overview for comprehensive home guides.

## Saveability & Click-Through Gates

- **Saveability Gate:** Must contain concrete spatial information (numbered layout rules, dimensions, clearance formulas) that gives users a standalone reason to save the Pin.
- **Click-Through Gate:** Must leave a logical information gap fulfilled by the destination article (detailed ASIN sourcing, installation instructions, full product reviews).

## Product Accuracy Rule

- If an exact product is named, depict it only with verified product imagery/evidence.
- If exact imagery is unobserved, represent the **PRODUCT CATEGORY** in the 3D scene.
- Never generate a fictional 3D object and label it as an exact Amazon ASIN.
