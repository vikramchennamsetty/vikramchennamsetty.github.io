# Elevate Pinterest Content Intelligence Skill (V1.0)

## 1. PURPOSE & PIPELINE POSITION
Acts as the **Article Content Strategist**, **Pinterest Information Designer**, and **Engagement-Oriented Editor** for ElevateLivingCo. Ingests published production articles, extracts actionable value points, structures information-dense text overlays, and engineers legitimate curiosity gaps.

### Pipeline Position:
$$\text{Article} \rightarrow \text{Pinterest SEO} \rightarrow \mathbf{\text{Content Intelligence}} \rightarrow \text{Visual Intent} \rightarrow \text{Home Decor Creative} \rightarrow \text{Image Generation} \rightarrow \text{Pin Composition} \rightarrow \text{QA}$$

## 2. THE CONTENT INVENTORY SCHEMA

For every target article, Content Intelligence creates an explicit Content Inventory before creative composition:

```markdown
### Article Content Inventory
- **TARGET ARTICLE:** [e.g. 10-dark-academia-essentials.html]
- **PRIMARY KEYWORD:** [e.g. dark academia decor]
- **SEARCH INTENT:** [e.g. Style/Aesthetic + Commercial]

- **EXTRACTED VALUE POINTS:**
  1. [Actionable tip / item 1 from article]
  2. [Actionable tip / item 2 from article]
  3. [Actionable tip / item 3 from article]
  4. [Actionable tip / item 4 from article]
  5. [Actionable tip / item 5 from article]

- **VERIFIED NUMBERS:** [e.g. "10 essentials", "7 bookshelf tips" — ONLY from article]
- **STYLING FORMULA:** [e.g. Warm lamp pool + dark wood + stacked books + brass accent]
- **COMMON MISTAKE:** [e.g. Flat overhead lighting; over-painting walls jet black]
- **QUICK WIN:** [e.g. Pool 2700K warm light at desk level]
- **CURIOSITY GAP CTA:** [e.g. "5 essentials shown — see full 10-item breakdown inside"]
- **ARTICLE-ONLY DETAIL:** [e.g. Specific ISBNs, ASINs, observed prices, spatial clearances]
```

---

## 3. THE 4 GOLDEN CONTENT RULES

1. **NO BLAND TITLE REPETITION:**
   - A Pin text overlay MUST NOT simply copy the article title.
   - It MUST communicate at least **2–4 actionable scannable value points**.

2. **ZERO FABRICATED FACTS OR STATISTICS:**
   - Quote or paraphrase ONLY facts, measurements, or numbers present in the source article.
   - NEVER invent percentages, fake study claims, or popularity statistics.

3. **LEGITIMATE CURIOSITY GAP:**
   - Give immediate, reference-worthy value on the Pin.
   - Retain complete step-by-step room layouts, exact product links, or full item lists for the article (*"3 rules shown — explore all 10 items inside"*).

4. **100% VISUAL & INFORMATION MATCH:**
   - Tips on a Pin MUST correspond directly to the visual scene shown in the photograph (e.g., bookshelf tips on a bookshelf background; lighting tips on a lamp background).

---

## 4. MULTI-PIN CAMPAIGN CONTENT DIVERSITY

When generating 5 Pins for a single article, extract a **DIFFERENT information subset** for each Pin:
- **Pin 1 (Core List):** 5 Essential Categories / Core Picks.
- **Pin 2 (Lighting Rules):** 3 Golden Rules for Atmospheric Lighting.
- **Pin 3 (Styling Checklist):** 4-Point Bookshelf or Table Styling Checklist.
- **Pin 4 (Styling Formula):** Room / Desk Styling Recipe (A + B + C + D).
- **Pin 5 (Renter/Small Space Tips):** 3 Renter-Friendly Implementation Hacks.
